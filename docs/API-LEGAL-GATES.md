# 红果上游接口：授权、验证、切换门禁

## 项目认识
之前对 `yangbin1322/hongguo-player` macOS 1.2.31 的二进制进行了静态研究，发现 `hg-go/pkg/hgapi`、登录、播放、弹幕与评论函数符号，以及部分 `fqnovel.com`/`snssdk.com` 服务域名。这足以证明目标客户端包含协议适配代码，但 **无法证明作者取得官方授权，无法证明每个接口当前可用**。本项目不承诺复制非公开签名算法或绕过客户端安全机制。

## Provider 分级
- MockProvider：第一天可用，独立运行，供 UI 与交互验证。
- LicensedDemoProvider：使用开发者自有版权/公开许可的测试短剧素材或自建媒体，验证真实播放能力。
- AuthorizedHongguoProvider：只在取得正式授权、文档、测试账号、接口配额和内容播放许可后开发/启用。

## 授权核查清单
1. 第三方 Windows/macOS 客户端是否允许接入（明确产品/系统/地域/期限）。
2. 账号登录授权方式（SDK / OAuth / 扫码）与令牌生命周期。
3. 内容元数据、播放源、CDN、清晰度、DRM/解码授权和播放场景。
4. 弹幕、评论读写、收藏、历史进度是否包含在合作范围。
5. 限流、密钥轮换、生产/沙箱环境、测试案例、隐私与数据处理协议。
6. 商业化权利（如收费、广告和再分发）与发行证书。

## 接入质量 Gate
- G0：只有静态线索 → UI 标为演示/不可用；不启动未授权请求。
- G1：取得官方文档及授权确认 → 建立可审查 Provider 与测试环境。
- G2：完成合法测试账户的登录、播放、评论、弹幕、历史的端到端双端核对 → 方可将相应 capability 标为 `ready`。
- G3：隐私、审计、发布授权和内容许可完成 → 方可上线正式渠道。

## 安全规范
不得要求开发 Agent 提取真实用户 Token、规避请求风控、绕过 DRM 或将设备签名秘钥复制到仓库。开源项目参考只能在许可证允许的前提下使用；`yangbin1322` 为闭源参考，禁止复制其二进制或宣称已得到源码。
