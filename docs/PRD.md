# PRD — 快剧短剧 Windows/macOS 客户端

## 1. 产品目标
在 Windows 11（优先）、macOS 上构建可独立分发的短剧客户端。设计系统与各页验收清单分别见 `docs/DESIGN.md` 和 `docs/UI-ACCEPTANCE.md`。首版必须能完整运行 **Mock 模式**，即使红果上游不可用也能操作、演示、测试；正式上游登录、评论、云同步等属于经验证和授权后才开放的能力。

## 2. 核心用户路径
启动 → 推荐/分类/搜索 → 详情 → 选集 → 播放 → 弹幕/评论 → 收藏/历史 → 登录与多端同步（仅在授权接口就绪后）→ 设置、更新。

## 3. 页面和业务需求
|编号|页面|关键功能|
|---|---|---|
|01|首页推荐|推荐 banner、今日上新、分类、排行榜、继续看、加载骨架/空态/异常|
|02|搜索结果|搜索建议、搜索历史、热门词、筛选、排序、结果跳详情/播放、翻页|
|03|短剧详情|剧集简介、演员、标签、状态、季列表、1-20 分组、选集、收藏、分享|
|04|视频播放|9:16/16:9 自适应、播放暂停、Seek、音量、倍速、画质、下一集、全屏、画中画支持检测|
|05|评论互动|最新/最热、分页、评论、回复、点赞、删除自己的评论；Mock 可演示；上游写操作必须能力门控|
|06|弹幕设置|弹幕开关、密度、字号、速度、透明度、关键词屏蔽、输入与发送；分轨时间轴|
|07|我的收藏|收藏/取消、分类、排序、批量管理、本地优先与云端冲突提示|
|08|观看历史|按日期、进度、续播、批量删除、清空、已看完状态、记录同步错误提示|
|09|账号登录|手机号验证码、二维码登录的 UI 和模拟状态；真实认证必须经过授权接口门槛；会话过期与退出|
|10|应用设置|主题、启动项、解码/画质偏好、快捷键、缓存、日志、隐私、版本更新状态|

## 4. 非功能需求
- 应用为 Go/Wails v2 + Vue 3/TS + Vite；使用 Pinia、Vue Router；SQLite 本地数据（开启 WAL）；系统秘钥链储存令牌。
- Mock 模式可离线执行 10 页 E2E，并明确标注演示数据；永不把 Mock 登录称作官方账号登录成功。
- 适配 1448×1086 原图及 1366×768、1920×1080、2560×1440；最低可接受主工作区 1180×720，窄屏可适度滚动。
- 支持 Windows 11 x64；macOS 13 Ventura 或更新版本（arm64/x64），跨系统构建不能假装已验证。
- 错误态、空态、超时、登录状态、权限异常必须可测试；日志自动遮蔽认证信息。
- 不使用 Docker；CI 可使用 GitHub Actions 原生构建；不要求 MySQL/Redis/宝塔作为桌面运行依赖。

## 5. 非目标（第一阶段）
- 不擅自模拟官方账号、绕过 DRM、提取/持久化签名秘钥；不以未公开 API 作为功能成功标准。
- 不先做商用支付、广告、集中账户服务、版权分发。
- 不以整页图片覆盖实现 UI。

## 6. 发布定义
V0.1 完成统一设计系统 + 10 页可互动 Mock + 本地历史收藏；V0.2 加入授权媒体 Provider 和播放器稳定性；V0.3 仅在官方授权及验收通过后接入账户、弹幕评论写入、云同步；V1.0 满足稳定性、安全与发布签名门槛。
