# 十页 UI 验收规范

## 通用
- 对照本项目设计系统和实际界面截图，按页验收布局、键盘交互和状态反馈。
- 图中是视觉概念：部分文字、海报、数值为虚构占位；可用具有使用许可的替代素材，但保持画面构图、亮度和层次。
- 视觉比对基准 1448×1086；实际截图固定同尺寸，窗口内容区一致，不包含系统标题栏误差。
- 逐项核对：框架、左侧栏、顶栏、间距、主要卡片几何、背景渐变、控件大小、字体层级、滚动与边界；记录布局和交互偏差。
- 可使用 Playwright screenshot + pixel diff/SSIM 作辅助，但不可使用单一像素阈值伪装完美；图片素材不同须单独排除并记录。
- 在 1366×768、1920×1080、2560×1440 下检查无主要内容重叠；键盘可访问、基本 aria 标注。

## 每页独立检查
01-首页推荐：Hero/CTA、分类 chips、今日上新横排、榜单、继续看、侧边导航；顶部搜索可跳转。
02-搜索结果：搜索输入、建议下拉、筛选/排序、结果卡、最近搜索/热搜；输入变化、空结果、加载中。
03-短剧详情：海报、主创、分类、简介、观看/收藏/分享、分组选集、系列全季、推荐；集号切换一致。
04-视频播放：9:16 视频区域、进度条、暂停/Seek、集数、速度/音量/画质/全屏、右侧选集面板、失败提示；Mock 视频用授权可用短片或播放器模拟态。
05-评论互动：右侧评论抽屉、排序、输入、点赞、展开回复、关闭；Mock 发表不得同步到真实红果。
06-弹幕设置：时间轴弹幕、开关、位置、透明度、字号、速度、密度、关键词、输入；屏蔽规则可验证。
07-我的收藏：卡片网格、全部/在追/已看过、排序、取消收藏、批量管理、空态。
08-观看历史：日期分组、播放进度、筛选、续播、批量删除、清空二次确认；恢复后的进度精确。
09-账号登录：手机号输入、验证码计时、扫码 UI、协议勾选、错误提示、过期、重新登录；真实登录关闭时应显示“演示模式”。
10-应用设置：外观、播放器、弹幕、下载缓存、快捷键、路径/权限、版本检查；所有设置重启后保留。

## Definition of Done
每个页面有：可访问路由或独立 UI 状态、源码、操作演示、单测、E2E、1448×1086 截图、视觉验收记录。未经上述证据不得标记完成。
