# 金帝短剧隐私说明

适用范围
本说明适用于目前的桌面演示版本。应用提供本地演示目录和自制视频，可由运营方配置授权媒体目录。演示账户与红果账户无关。

保存在本机的信息
收藏、观看进度、搜索历史、设置、演示账户状态、分集点赞，以及你写入的本地评论和弹幕会保存在本机。桌面版使用本地 SQLite 数据库和 WebView 缓存。已发表且尚未确认保存的评论暂存在本机 WebView，确认后清除。遇到版本冲突时保留待补写记录，并提示用户处理。浏览器预览的收藏、历史、搜索记录、设置、分集点赞和演示账户使用浏览器本地存储，评论和弹幕为临时演示。演示登录不会发送短信。填写手机号时，应用只用末四位生成本机显示名，无需使用真实号码。

联网与分享
内置目录、演示视频和已配置的本地片库可离线使用。Windows 桌面版播放本地片库时，媒体在应用和本机回环地址之间传输。点击「检查更新」会向 GitHub 查询该项目的公开发布记录，GitHub 会收到常规连接信息。点击「校验并下载安装包」并选择保存位置后，应用从 GitHub 下载并校验文件。保存路径只在本机使用。发布页入口会打开系统浏览器。Windows 安装程序在需要时可能从 Microsoft 获取 WebView2 运行时。应用不会把观看、收藏、搜索、分集点赞、评论、弹幕或诊断日志同步到上游服务。

管理本地信息
可在收藏和观看历史页面批量删除记录，在搜索页清空搜索历史，在评论页取消本集点赞，在设置中清理下载缓存，或通过退出演示账号移除演示显示名。可在设置的「关于与更新」中创建本地数据库备份，并从所选备份补回缺失的收藏和观看历史。恢复过程在本机完成，保留当前已有记录。桌面的数据库、日志及应用备份位于当前用户的 JindiDrama 配置目录。删除该目录会删除其中的数据及备份，操作前请退出应用。独立导出的演示视频保存在你选择的位置。

诊断与反馈
日志主要记录故障，常见凭据会被遮蔽。桌面版在本机保存运行标记，用于在下次启动时识别上次运行是否未正常结束。标记记录版本、平台、启动时间和窗口就绪状态。运行标记不包含崩溃堆栈或用户内容。「复制诊断信息」把最近的日志放入剪贴板，由你决定是否分享。反馈时可通过本项目的 GitHub Issues 联系维护者，请先检查准备分享的内容。
